## 日期、利率与初始余额

- period 取**实际付款日的月份**。回收期采用 Deere 的财政周期。首期 2024-07-15 同时覆盖 2024-04-29 至 2024-06-23 的回收；计算首期预期回款时，原计划的 5 月和 6 月合并。10-D 封面报告期、服务商回收期与两种票据计息期请分别使用相应字段。
- 金额为美元，利率与占比统一用小数，0.0542 表示 5.42%。利息用余额乘年率再乘合同天数分数。WAL 按偿还本金加权；投资者 IRR 用每档发行价、实际支付日期和该档本息计算。仍存续票据的全期限回报取决于未来现金流。
- 2024-04-28 截止日含应计利息余额 $1,694,001,151.31，减去已计利息 $23,999,934.84，得到首期月报期初本金 $1,670,001,216.47。用于决定偿债金额的初始 Note Value 为 $1,562,473,742.82；票据初始面值合计 $1,523,411,000。请明确每个比率选用的分母。
- 正常月应付本金以**期初 Note Value 减期末 Note Value，再加上期本金短缺**确定，并受契约上限及到期条款约束。Note Value 按 8.85% 折现剩余计划回款，合同还规定逾期达 180 日、收回设备或清算后的估值处理。观察期资料可直接用披露值做回测。预测期使用的估值近似须单列说明。
- 19,156 笔合同中，10,810 笔按年还款，占截止日披露余额 **62.39%**；按月还款的余额占 **31.91%**。优先使用原始计划回款刻画季节性。原始计划是发行日快照，在较晚截面使用时需调整已摊还、提前还款及损失。
- prepayment 是服务商披露的月度美元金额。29 期中 7 期为负，正负号与累计额变动逐期相符。公开表格未提供逐笔自愿提前还款的构成。该金额直接年化得到的数值缺少标准 CPR 对应的计划存续本金分母。预测期的非负 CPR、违约率和回收率须标记为模型参数。发行人展示的 16% CPR 可用作对照；若采用仓库计划中的压力倍数，标记为情景假设。
- 当期净损失可含 180 日以上逾期及已收回未清算设备的估计损失变动。gross_losses、accrued_loss_change 与 recoveries_signed 按月报原符号相加得到 net_loss。逾期余额是存量，当期净损失是流量；累计净损失比例的分母为初始池余额。
- 99.1、99.3 的报告百分比按披露精度保留，按金额反算可能更精确。池级数据可用于历史回放与压力测试。本包未取得逐笔贷款台账，也没有用多个边际分布拼出虚构的联合分布。

## 来源与复现

raw/prospectus.pdf 为 Deere 官网提供的印刷版。raw/tables/ 是从每期 SEC 附件提取的表格文本，每份首行记录原始 URL。该目录保存用于取数的表格行；EDGAR 完整申报由 Sources.csv 链接。raw/ 中另外保存 6 个月份的发行人 Excel 原件，覆盖 2025-05、06、09 和 2026-04、06、08。下载索引和 SHA-256 在 SourceFiles.csv 中。资料冻结日为 2026-11-25。

在本目录执行以下命令。第一步只用 Python 标准库。第二、三步分别使用 pypdf 和 openpyxl。

```text
python -m pip install -r requirements.txt
python build.py
python extract_prospectus.py
python verify_issuer.py
python verify_release.py
```

build.py 校验日期连续性、余额滚动、各档本息、两种计息天数、同级按比例偿付、逾期分桶、净损失、累计提前还款、储备变动和资金分配。美元比较通常容许两分钱的披露舍入，分项求和及整美元披露的超额抵押使用各自容差。验证结果适用于已发生的 29 期，未来压力情景和成员 B 的模型仍须与这些基准表单独比对。
