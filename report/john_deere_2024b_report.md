## 0. 一句话结论与阅读路线

**这个结构把损失压力几乎全部推给了证书，而不是票据。** 在把净损失率推到实现值的 24 倍
（15.92%/年，投影期累计净损失 65.5M，已超过 2.5% 的超额抵押 39.06M）之后，A-3 在 42 格网格里
**没有任何一格出现本金短缺**；A-4 只在"24 倍损失 + 零自愿提前还款"这一个角上短缺 **1,513,336 美元**
（占其原始本金 1.65%）。同期**证书的现金从 48.7M 被打到 0**。

因此本文对题目的回答分两层：

- **本金偿还与信用**：损失由证书、储备、超额抵押依次吸收；票据接近"结构免疫"，破防点在检验范围之外。
- **期限与回报**：真正移动票据期限的是**清仓赎回权**（行使 3.663 年 / 不行使 4.177 年，差 0.51 年），
  而损失与速度只能移动 0.15–0.20 年。**赎回权改变的是期限与再投资，不改变回报**——
  按面值赎回，A-4 的 IRR 在行使与不行使之间只差 **0.24 bp**（5.3084% vs 5.3108%）。

# §4 汇总池现金流与瀑布假设

## 4.1 为什么必须用 Note Value 而不是摊销表

契约把"应付本金"直接定义成 Note Value 的下降额，而 Note Value 本身有明确定义：

> "The note value of the receivables on any payment date is the present value of the unpaid scheduled
> payments on the receivables, discounted at 8.85%."（招股书印刷页 92）
>
> "The aggregate amount of principal payable on the notes on each payment date will generally be equal
> to the reduction in the note value of the receivables during a collection period."

这条定义可以直接验证：把 73 期合同计划回款按 8.85%（月复利；首个剩余收款月折一期）折现，得到
**1,562,473,742.8171**，与披露的初始 Note Value 1,562,473,742.82 相差 **0.0029 美元**。

于是整个瀑布不需要贷款级数据：只要给出"剩余应收款的未付计划回款"，Note Value 与本金分配同时确定。
本项目因此被定位为**汇总池现金流与压力测试模型**，不声称实现贷款级预测。

## 4.2 三个校准量与一个存活状态

| 量 | 取值 | 含义 |
|---|---:|---|
| 摊销费率（季节性口径） | **5.7541%/年** | 使 73 期计划回款恰好耗尽期初本金 1,670,001,216.47 |
| 同上，含应计利息口径 | 5.0236%/年 | 口径交叉检验（披露加权 APR 4.745%） |
| Note Value 折现率 | 8.85%/年 | 合同常数 |
| 月度收款季节权重 | 1.245 / 1.306 / 1.488 / 1.277 / 0.435 / 0.622 / 0.718 / 0.906 / 0.886 / 1.159 / 0.743 / 1.214 | 1–12 月，均值 1 |

**季节性不是修饰**：池内 62.39% 的余额按年付，到期日集中在春播与秋收（3 月 1.49 倍、5 月 0.43 倍）。
把利息按月平滑计提会让 Note Value 的回放误差翻倍（0.561% → 0.246%）。
权重不受去趋势方式影响（对数线性 0.246%、对数二次 0.232%、12 个月移动平均 0.284%）。

**代价必须写明**：季节性让含应计口径与披露 APR 的差从 8 bp 扩大到 **28 bp**。校准出的费率是
**摊销因子**而非合同 APR，两个口径的数字都保留在 `calibration.csv`，不做取舍隐藏。

## 4.4 现金不闭合：一条必须写入限制的边界

用已披露的汇总字段反解每月隐含池利息（年化），四种口径的均值绝对误差为 1.36–2.64 个百分点
（最大 3.76–7.43 pp），而披露的加权 APR 稳定在 4.81%。**`Total cash receipts` 与"池余额下降 + 净损失"
之间不存在可用的一阶恒等式**，个别月份甚至反号。

原因在结构上：99.3 不披露"本金回收 / 利息回收"的分项；`prepayment` 的定义在 Sale and Servicing
Agreement 而非招股书（角色 A 检索后确认协议中**没有**名为 Prepayment Amount 的独立定义）；
且 `prepayment` 有 7 个月为负。

**因此模型只保证结构恒等式**（可分配额 = 四个来源之和；= 十个顺位之和），不以"复现服务商现金对账"
作为校验对象。校验对象改为 Note Value 序列、池余额序列与分档本金序列——这三条都能由计划回款结构直接推出。

## 5.4 唯一出现票据短缺的格子

| 项 | 值 |
|---|---:|
| 损失率 | 15.92%/年（24× 实现值） |
| CPR | **0%**（无任何自愿提前还款） |
| 该格累计净损失 | 70,440,245 |
| A-4 收回本金 | 90,197,888 / 91,711,000 |
| **A-4 短缺** | **1,513,336（占原始本金 1.65%）** |

# §6 投资者收益与风险：谁承担什么

> §5 已经说明"压力几乎没有影响"。本节解释为什么，并把这句容易被误读的话换成分档的、可执行的表述。

## 6.1 票据：期限由赎回权决定，不由损失决定

| 驱动 | A-4 WAL 变化 | A-3 WAL 变化 |
|---|---:|---:|
| 清仓赎回权：行使 → 不行使（Base） | **3.6630 → 4.1767（+0.51 年）** | 2.6483 → 2.6536（+0.01 年） |
| CPR 0 → 16%（Base 损失，不行使） | 4.3035 → 4.1008（−0.20 年） | 2.6994 → 2.6276（−0.07 年） |
| 损失 1× → 24×（CPR 10%，不行使） | 4.1767 → 4.3243（+0.15 年，非单调） | 2.6536 → 2.6259（−0.03 年） |

**赎回权是最大单一变量**（对 A-4 而言是 0.51 年，是损失效应的 3.4 倍、速度效应的 2.6 倍）。
A-3 对三者都不敏感，因为它无论哪一支都在 2028 年被清偿。

## 6.2 赎回权的性质：改变期限与再投资，不改变回报

这一点必须说准，否则 §6 的 IRR 表会自相矛盾。

清仓赎回是**按面值**赎回（未偿本金 + 应计未付利息）。因此：

| 口径 | A-4 行使 | A-4 不行使 | 差 |
|---|---:|---:|---:|
| 按面值 IRR | **5.3084%** | **5.3108%** | **0.24 bp** |
| WAL | 3.6630 年 | 4.1767 年 | 0.51 年 |

**所以正确的表述是**：赎回权带来的是**期限风险与再投资风险**（多出来的是 0.51 年的现金流不确定性），
**不是回报风险**；而且方向是"**不行使 → 期限延长到 4.18 年**"，
不是"行使 → 损失"。全部 7 个情景的 A-4 面值 IRR 落在 5.3084%–5.3136%（跨度 5.2 bp）。

**赎回时点是临界的**（按票面口径验证）：

| 付款日序号 | 月份 | 期末 Note Value | 占阈值 156,247,374 比例 | 可否行使 |
|---:|---|---:|---:|---|
| 第 43 期 | 2028-01 | 172,472,819.46 | 110.38% | 否 |
| 第 44 期 | 2028-02 | 155,559,902.87 | 99.56% | **是** |

发行人的估值假设是"第 43 个付款日"（首期 2024-07-15 起算）= 2028-01；模型从 2026-11 冻结截面重算，
落在**第 44 期 = 2028-02，晚一期**，且首次穿越只低于阈值 **0.44%**。
起点不同（发行日 vs 冻结日）可以解释晚一期，但**这验证的是量级与方向，不能称为"吻合"**。

| **24×** | **0** | **11,956,730** |

证书是唯一按美元承担损失的档位：损失率每上升一档，证书现金近似等额下降（见 §5.3.2）。
**信用风险在这里，不在票据。** 到 24× 时证书现金归零、储备被抽走 77%，票据才开始接近边缘。

这与题目"损失如何影响投资者回报"的答案直接对应：**受影响的投资者是证书持有人，不是票据持有人。**

## 6.4 法定到期检查：什么条件下票据才会破

在所有 7 个情景与 42 格网格中，各档清偿月份都早于其法定最终付款日：

| 档位 | 法定最终付款日 | 情景中最晚清偿 | 网格中最晚清偿（41 格） | 余量 |
|---|---|---|---|---|
| A-3 | 2029-03-15 | 2028-05 | 2028-06 | 约 9 个月 |
| A-4 | 2031-05-15 | 2029-02 | 2029-10 | 约 19 个月 |

**唯一例外**：24×+CPR0 那一格，A-4 到抵押物耗尽的 2030-05 仍有 1.51M 未偿，
到 2031-05 法定到期时形成逾期本金。

**据此给出可执行的判断**（而不是"票据安全"）：

- 票据要发生本金损失，需要**累计净损失超过已实现的约 24 倍（15.92%/年）且同时几乎没有提前还款**；
- 只满足其中一个不成立：24× 但 CPR=10% → A-4 全额兑付；CPR=0 但损失 1× → 也全额兑付；
- A-3 的破防点**没有被找到**，因此它的安全边界只能表述为"在被检验的损失×速度曲面内"。

# §7 模型限制、治理与可复现性

## 7.1 四条硬限制

| # | 限制 | 影响 | 本报告如何处置 |
|---|---|---|---|
| L1 | **没有贷款级数据**（SEC 无 ABS-EE） | 不能做逐笔违约/提前还款建模 | 明确采用汇总池模型；不声称贷款级预测；`PoolComposition` 的边际分布**不**拼成联合分布 |
| L2 | **现金与池余额不能逐月闭合**（隐含年化利率 −2.7%~+6.8%） | 不能以"复现服务商现金对账"为校验 | 只保证结构恒等式；校验对象改为 Note Value / 池余额 / 分档本金三条可推序列 |
| L3 | **季节性拆分的口径代价** | 含应计口径与披露 APR 差 28 bp（平滑版为 8 bp） | 两套拆分并列输出（`feedback_split_comparison.csv`）；选季节性是因为它把 Note Value 误差减半 |
| L4 | **未建模 EoD 加速瀑布**（用户决定） | 顺序清偿下的 A-4 尾部损失是**上界** | 报告显式声明；法定到期检查给出缺口金额而非"切换后的分配" |

## 7.2 三条假设依赖

| 假设 | 取值 | 若被质疑 |
|---|---|---|
| OC 恒定为初始值 39,062,743 | 29 期实测不变；招股书"intended to maintain the initial overcollateralization amount" | 若 OC 有台阶，票据保护会减弱 |
| 清仓买回价 = Note Value | 作为单一现金流入；OC 不再单独计入 | 若买回价更低，票据可能不满额赎回（角色 A 已提醒 OC 不可重复计入） |
| 损失率以净损失直接校准 | 不启用独立 `recovery_rate` | 若另建"违约发生额 × 损失率"模型，需保证回收只作用一次 |

## 7.3 治理与可复现

- 一条命令重建全部结果：`python member_B/run_all.py --stage all`，门槛失败即非零退出。
- **754 项校验**写入 `Validation_B.csv`，沿用角色 A 的表结构（`period, check, difference, tolerance, status`）。
- 参数登记表 `docs/assumptions.md`：每个数字有"参数名 / 取值 / 来源 / 依据 / 敏感性区间 / 代码位置"六列。
- 角色 A 提供的 5 个附件（Schedule C、发行人 WAL、损失曲线、本金网格、回购对照）已在
  `member_B/reference/` 留档并记录 SHA-256。
- 与角色 A 的口径核对：A 对 11 项问题的答复已逐条并入，纠正了我三处判断
  （回购现金含利息、损失同龄基准为 0.34%、例外不止两种），详见 `plans/open_questions_b.md`。
